# TagesPilot

Die erste KI-native Praxissoftware für Tagespflegeeinrichtungen in Deutschland.

## Deploy auf Vercel

1. Dieses Repo in GitHub pushen
2. vercel.com → "New Project" → GitHub Repo wählen
3. Framework: Vite → Deploy → fertig

## Lokal starten

```bash
npm install
npm run dev
```
